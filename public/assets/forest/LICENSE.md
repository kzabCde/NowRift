# NowRift original procedural art

All PNGs in this directory were created for NowRift by `scripts/generate-assets.py`.
No external game artwork, fonts, or image services are used. These original assets
are provided under CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/).
The generator is the editable source of the assets. Each character atlas has ten
frames: idle, three walking frames, cast/attack, hit flash, two death frames,
and two breathing idle frames.
