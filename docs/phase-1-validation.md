# Phase I baseline

The published workspace restored the Phaser 4 forest slice, original art, four weapons, five enemy archetypes, eleven bounded blessings, a two-phase Forest Guardian, keyboard/touch controls, Focus mode, guest menus, local run records and PWA caching. Those existing regression assertions remain in the test suite.

Phase II builds on these files rather than creating a parallel combat engine. See [Phase II validation](phase-2-validation.md) for current commands, coverage, performance observations and limitations. The practice bot uses seed 1 for a verified normal-stat victory; arbitrary bot seeds may lose.
